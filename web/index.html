Find the published effect sizes a study plan needs

Describe the study you are planning. AI agents, on Claude or on OpenAI's models as you choose under Agents, search PubMed, Europe PMC and ClinicalTrials.gov, read the papers they can open, and pull out the statistics the papers report, each with the sentence or table row it came from. Opus 5.5 reads what each result estimates and with which model, and how that compares with your plan; once you have decided what to include, it summarizes what the papers you kept report.

  • Searches the literature

    PubMed and Europe PMC, open-access full text from PubMed Central and Unpaywall, and results posted on ClinicalTrials.gov.

  • Every number is quoted

    Each value carries its quote, which is checked against the paper. Anything that fails a check goes to a second, stronger review.

  • You decide

    Review the papers one at a time, including or excluding each result. Opus 5.5 checks for studies counted twice and summarizes what you kept, number by number.

Your paragraph and the text of the papers are sent to Anthropic's API to be read. Don't paste anything you can't share with it.

Agents

The agents do the reading: a manager model plans the search, reviews what fails a check, reads what each paper's results estimate and with which model, and writes the summary; worker models screen every record and extract every paper's statistics, each with its quote; and code runs the searches and checks every quote against the paper. They can run three ways: on Claude with an Anthropic API key, on OpenAI's models with an OpenAI API key, or on OpenAI's models through your ChatGPT Plus or Pro plan, with no key.

      Step 5

      Summary

      The head agent recommends a planning effect size for each outcome and explains its clinical importance, evidence, assumptions, and alternatives using DELTA². Each recommendation says how its source result’s estimand compares with the planned one, and each effect size the plan needs, what its values estimate and with which models. Source values stay linked to the papers; derived effects show their calculation. A provisional choice identifies what still needs to be resolved.
