Effect Size Finder

Find the published effect sizes a study plan needs

Describe the study you are planning. Claude, or an OpenAI model if you prefer, searches PubMed, Europe PMC and ClinicalTrials.gov, reads the papers it can open, and pulls out the statistics they report, each with the sentence or table row it came from. You decide what to include, and Opus 5.5 summarizes what the papers you kept report. Use your own Anthropic or OpenAI API key, or connect your ChatGPT subscription through a local helper.

  • Searches the literature

    From the top down: reviews and meta-analyses first, then studies in your population, then papers whose full text reports the outcome (Europe PMC), then wider, plus the trials the reviews cite. Also results posted on ClinicalTrials.gov.

  • Every number is quoted

    Each value carries its quote, which is checked against the paper. Anything that fails a check goes to a second, stronger review.

  • You decide

    Include or exclude each result, then export what you kept as CSV or JSON.

Agents

The agents read your problem, plan and run the search, screen the records and extract what the papers report. Choose how they run: on Anthropic's or OpenAI's API with your own key, or on your ChatGPT subscription through a local helper.

How the agents run

OpenAI has nothing like Claude's web fetch, so a PDF this page may not download is not fetched: the abstract is read instead, and you can upload the PDF.

Use your ChatGPT subscription here

The local helper handles ChatGPT sign-in and model calls on your computer. Set it up once to start automatically on macOS or Linux, then connect below and sign in in the companion window. Your searches stay in this browser, and usage counts against your ChatGPT plan.

One-time setup: install the automatic helper
  1. Get the code:
    git clone https://github.com/hyungrok-do/effect-size-dev.git
cd effect-size-dev
  2. Install it, on macOS or Linux:
    python3 -m venv .venv
.venv/bin/python -m pip install -e .
    or on Windows:
    py -m venv .venv
.venv\Scripts\python -m pip install -e .
  3. Enable automatic startup on macOS or Linux with systemd (stop an earlier esf serve with Ctrl+C first):
    .venv/bin/esf helper install
    On Windows, start it manually and keep its terminal open:
    .venv\Scripts\esf serve

Setup opens a local page to pair this browser once; it carries the server's access key. Use this same browser, return here, and click Connect ChatGPT. After automatic setup, you can close the terminal: the helper runs in the background and starts when you log in. Keep the companion window open while searching.

Using another browser? Run .venv/bin/esf helper open to pair it. Check the helper with .venv/bin/esf helper status. ChatGPT sign-in is needed again after the helper restarts.

After git pull --ff-only, use .venv/bin/esf helper restart to load updates. Remove automatic startup with .venv/bin/esf helper uninstall. Manual startup with esf serve remains available.
